### Changes Made

2. **Next.js Migration**: Moved all Next.js files to `apps/web/` maintaining existing structure
3. **FastAPI Setup**: Created basic FastAPI backend with health endpoints and CORS configuration

5. **Development Environment**: Added API proxy configuration for seamless development experience
6. **Docker Support**: Added docker-compose.yml for containerized development (optional)

### Key Features
- **Concurrent Development**: Run both services with `npm run dev`
- **API Proxy**: Frontend can call `/api/*` routes that proxy to FastAPI backend
- **Independent Deployments**: Each service can be built and deployed independently
- **Shared Dependencies**: Root-level tooling and shared packages support

- `npm run dev:api` - Start only FastAPI backend
- `npm run build` - Build the frontend for production
